# Audio asset licenses

All sound effects in `/public/audio/sfx/` (click.wav, pop.wav, correct.wav,
wrong.wav, win.wav) were **synthesized from scratch** by `scripts/gen-sfx.mjs`
in this repository (pure generated sine/triangle tones, no third-party samples).

License: **CC0 / public domain** — free to use, no attribution required.

TTS clips under `/public/audio/tts/` are generated at seed time from the
project's own lesson text via the Google Gemini TTS API (see scripts/seed-tts.mjs).
